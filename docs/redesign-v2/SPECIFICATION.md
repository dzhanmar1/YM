# YM Aura v2 — Техническая спецификация мобильного редизайна (PWA)

## 1. Обзор и цели
Данная спецификация описывает полный редизайн мобильного интерфейса (PWA) приложения **YM (Yandex Music)** на основе дизайн-системы **YM Aura v2** из Google Stitch (проект `6406744647732734215`).

Дизайн-макеты и готовый HTML сохранены в репозитории:
- `docs/redesign-v2/01-home-flow.html` — **v2 Главная — Поток**
- `docs/redesign-v2/02-player-immersive.html` — **v2 Плеер — Иммерсивный**
- `docs/redesign-v2/03-lyrics-karaoke.html` — **v2 Текст — Караоке-поток**
- `docs/redesign-v2/04-collection-media.html` — **v2 Коллекция — Медиатека**

## 2. СТРОГИЕ ГРАНИЦЫ: ЧТО НЕЛЬЗЯ ТРОГАТЬ (FORBIDDEN) 🚫
При редизайне **категорически запрещено** изменять или ломать следующие модули и логику:

1. **`src/components/AudioEngine.tsx`**:
   - **НЕЛЬЗЯ** менять вызовы `navigator.audioSession.type = 'playback'`, инициализацию Web Audio API, unlock на `touchstart`/`touchend`.
   - **НЕЛЬЗЯ** возвращать `seekforward` / `seekbackward` в `MediaSession` (на iOS это заменяет кнопки «След./Пред.» на «10 сек вперед/назад»).
   - **НЕЛЬЗЯ** менять размеры обложек `MediaSession` (использовать строго `100x100`, `200x200`, `400x400`, `600x600`, `800x800`, `1000x1000`, иначе iOS ломает отображение на экране блокировки).
   - **НЕЛЬЗЯ** добавлять вызов `audio.load()` при смене трека (это ломает фоновое воспроизведение на iOS Safari).

2. **`src/api/webAdapter.ts`**:
   - **НЕЛЬЗЯ** трогать логику проксирования аудио (`/api/stream?trackId=...`), авторизации и хранения токена (`localStorage` + `document.cookie` fallback).
   - **НЕЛЬЗЯ** трогать обработку станций `startCustomWave` (маппинг `activity:*`, фильтры языка `not-russian`, `without-words`, очистку `restrictions2`).

3. **`src/store/playerStore.ts`**:
   - **НЕЛЬЗЯ** ломать логику дозагрузки волны: автоматический prefetch треков при `queue.length - queueIndex <= 3`. Без этого плеер замолчит в фоновом режиме на iPhone.
   - **НЕЛЬЗЯ** удалять методы `playTrack`, `togglePlay`, `nextTrack`, `prevTrack`, `seek`, `likeTrack`, `sendRotorFeedback`.

4. **Десктопная версия (Tauri / Electron / Web Desktop)**:
   - Приложение работает как на Desktop, так и на мобильных устройствах (`isMobile`).
   - Редизайн применяется для мобильного режима (`isMobile`), либо должен быть адаптивным, не превращая десктопное окно в узкую телефонную полоску шириной 400px.

## 3. ДИЗАЙН-СИСТЕМА И ТОКЕНЫ (YM Aura v2)

### Цветовая палитра (Dark-first UI)
- **Фон (Background / Surface):** `#10131C` (`dark-surface`, `dark-background`)
- **Контейнеры поверхностей:**
  - `lowest`: `#0B0E17`
  - `low`: `#181B24` (карточки, чипы, инпуты)
  - `container`: `#1C1F29` (фоны списков, подложки)
  - `high`: `#272A33` (активный капсульный док, модалки)
  - `highest`: `#32343E` (неактивные полосы прогресса)
- **Акцентный цвет:** `#FF3B5C` (неоново-малиновый, `accent`)
- **Текст и контент:**
  - Основной: `#E0E2EF` (`dark-on-surface`)
  - Второстепенный / Muted: `#9EA3B8` (`muted`)
  - Обводки / Borders: `#2D303A` (`dark-outline-variant`)
  - Успех / Третичный (рост в чарте): `#62DDA0` (`dark-tertiary`)

### Типографика
- **Display / Заголовки:** `'Manrope', sans-serif`
  - Крупные цифры и акценты: `display-lg-mobile` (28px / line-height 34px / bold)
  - Заголовки секций: `headline-md` (20px / bold)
- **Основной текст и лейблы:** `'Inter', sans-serif`
  - `title-lg` (18px / semibold)
  - `title-md` (16px / semibold)
  - `body-md` (14px / regular)
  - `body-sm` (13px / regular)
  - `label-md` (12px / medium)
  - `label-sm` (11px / medium)
- **Моноширинный (позиции чарта, счетчики, длительность):** `'JetBrains Mono', monospace` (`mono-sm`: 12px tabular-nums)

### Иконки
- В проекте используется `lucide-react`. Рекомендуется использовать эквивалентные иконки Lucide с классами размера (`size={20}`, `size={24}`):
  - `graphic_eq` -> `Radio` или `AudioWaveform`
  - `play_arrow` -> `Play` (с `fill="currentColor"`)
  - `pause` -> `Pause` (с `fill="currentColor"`)
  - `skip_next` / `skip_previous` -> `SkipForward` / `SkipBack`
  - `search` -> `Search`
  - `tune` / настройки -> `SlidersHorizontal` или `Settings`
  - `library_music` -> `Library`
  - `favorite` -> `Heart`
  - `shuffle` -> `Shuffle`
  - `repeat` -> `Repeat`
  - `headphones` -> `Headphones`

## 4. АРХИТЕКТУРА И ЭКРАНЫ ДЛЯ РЕАЛИЗАЦИИ

### Экран 1: Главная — Поток (`src/pages/LandingPage.tsx`)
1. **Airy Top Bar**:
   - Логотип `YM` с неоновой точкой `#FF3B5C`.
   - Поисковая капсула-кнопка (при клике переключает на таб `search`).
   - Кнопка настроек и эквалайзера (открывает настройки / эквалайзер).
2. **Acoustic Orb ("Моя Волна")**:
   - Центральная круглая витрина волны с мягким неоновым свечением (`blur-3xl`, `bg-accent/15`).
   - Кнопка воспроизведения по центру орбиты.
   - Горизонтальный скролл чипов настроения волны: `Бодрое`, `Ночной драйв`, `Фокус`, `Незнакомое`, `Любимое` (подключены к `startWave` / `waveSettings`).
3. **Bento-сетка ("Собрано для вас")**:
   - Левая высокая карточка: **Премьера** (новинки, 20 треков).
   - Правая колонка из двух карточек: **Дежавю** и **Микс дня** (плейлист дня).
4. **Чарт Топ-100 (Live Chart Strip)**:
   - Список топовых треков с нумерацией и динамикой (`↑ +2`, `—`).
   - Клик по треку запускает воспроизведение.

### Экран 2: Иммерсивный плеер (`src/components/ImmersiveNowPlaying.tsx`)
1. **Шапка**:
   - Полоска свайпа вниз (`swipe-down handle`) для закрытия плеера.
   - Индикатор источника звука и качества (`LOSSLESS`).
2. **Центральная зона**:
   - Большая квадратная обложка трека с мягким атмосферным свечением.
   - Название трека и артист + кнопка лайка (Heart).
   - **Виджет предпросмотра текста**: аккуратная плашка с текущей строкой текста песни. Клик разворачивает экран караоке.
3. **Эргономичный Thumb-контроллер**:
   - Скруббер прогресса трека с текущим временем и длительностью.
   - Кнопки управления: `Shuffle`, `Previous`, большая центральная таблетка `Play/Pause`, `Next`, `Repeat`.
   - Быстрый доступ к утилитам снизу: `Похожие треки` (волна по треку), `Текст` (караоке), `Эквалайзер`, `Очередь`.

### Экран 3: Караоке-текст песни (`src/components/LyricsModal.tsx` или режим плеера)
1. Контекстная шапка: круглая микро-обложка, название трека, кнопка свернуть.
2. Синхронизированный поток текста (LRC):
   - Активная строка выделяется крупным шрифтом (`display-lg-mobile`), белым цветом и акцентной неоновой чертой под ней.
   - Неактивные строки приглушены (`text-muted/80`), плавный автоскролл за `currentTime`.
3. Нижняя плавучая капсула управления с кнопкой паузы и возврата к обложке.

### Экран 4: Коллекция — Медиатека (`src/pages/CollectionPage.tsx`)
1. **Шапка**: Заголовок "Коллекция", поиск по коллекции и скачанные треки.
2. **Полка плейлистов**: горизонтальная лента компактных карточек плейлистов пользователя.
3. **Любимые треки**:
   - Заголовок с количеством треков + кнопка «Перемешать».
   - Список треков с обложкой, длительностью, кнопкой волны по треку и кнопкой удаления из любимых.

### Общий компонент: Ergonomic Thumb Dock (`src/components/MobileBottomNav.tsx` + `MobileMiniPlayer.tsx`)
1. Закреплен внизу экрана с мягким градиентом подложки.
2. Содержит два уровня:
   - **Мини-плеер капсула**: мини-обложка, название трека, артист/волна, кнопка Play/Pause, кнопка Next, встроенная 2px линия прогресса по нижнему краю. Клик на карточку открывает Иммерсивный плеер.
   - **Pill-навигация на 3 таба**:
     - `Поток` (иконка `Radio`/`AudioWaveform`) -> `landing`
     - `Поиск` (иконка `Search`) -> `search`
     - `Коллекция` (иконка `Library`) -> `collection`
